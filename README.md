# MyChar Sync

Окно для переноса записей между JSON-выгрузками [MyChar: DnD](https://mychardnd.netlify.app/).

Синхронизируются:

- **Игроки** (`players`)
- **НПС** (`allies`)
- **Заметки / квесты** (`customNotes`)
- **Персонажи** целиком — если открыта полная резервная копия

Подходят и одиночный экспорт героя, и файл «Резерв» (`grimoire_backup_v1`).

## Запуск

```bat
python mychar_sync.py
```

Слева и справа откройте два JSON. Вкладки сверху — что сравнивать. Галочки — что копировать, стрелки — направление. Потом «Сохранить».

Одинаковые записи (даже с разными id) не отмечены. Отличающиеся и те, которых нет на другой стороне, отмечены сразу.

При сохранении по умолчанию герою выдаётся **новый id**. Иначе MyChar при импорте находит старого персонажа по id и кладёт данные не в тот слот. Галочку можно снять, если нужно обновить существующего героя на месте.

Перенос во вкладке «Персонажи» тоже всегда даёт новый id.

## Сборка exe

```bat
build.bat
```

Готовый файл: `dist\MyCharSync.exe`.
